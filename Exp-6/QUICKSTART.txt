METHOD A: Using phpMyAdmin (Recommended for beginners)
─────────────────────────────────────────────────────
1. Open browser and go to: http://localhost/phpmyadmin
2. Look for the "SQL" tab at the top of the page
3. Open the file: C:\xampp\htdocs\program-6\database_setup.sql
4. Copy ALL the SQL code (Ctrl+A, then Ctrl+C)
5. Paste it into the phpMyAdmin SQL editor (Ctrl+V)
6. Click the "Go" or "Execute" button (usually red/orange)
7. You should see success messages

METHOD B: Using Command Line
─────────────────────────────
1. Open Command Prompt
2. Navigate to: cd C:\xampp\mysql\bin
3. Run: mysql -u root -p
4. When prompted for password, just press Enter (default is blank)
5. Execute: source C:\xampp\htdocs\program-6\database_setup.sql;
6. Type: exit to close MySQL

METHOD C: Using MySQL Workbench (If installed)
──────────────────────────────────────────────
1. Open MySQL Workbench
2. Connect to localhost server
3. File → Open SQL Script
4. Select: database_setup.sql
5. Click "Execute" (⚡ icon)

❌ "Connection failed: Access denied"
✓ Solution: Ensure MySQL is running, check db.php has correct credentials

❌ "Table doesn't exist"
✓ Solution: Run the database_setup.sql script in phpMyAdmin

❌ "Login button doesn't work"
✓ Solution: Clear browser cache (Ctrl+F5), check console for errors (F12)

❌ "Page doesn't load"
✓ Solution: 
  - Check Apache is running (green in XAMPP)
  - Try: http://localhost/program-6/index.php
  - Check file permissions

❌ "Styling looks broken"
✓ Solution: Clear cache (Ctrl+F5), check if style.css exists in folder

❌ "Database setup script not working"
✓ Solution:
  - Check MySQL is running
  - Verify you're pasting ALL code from database_setup.sql
  - Try line by line in phpMyAdmin
  - Check for error messages in red text
